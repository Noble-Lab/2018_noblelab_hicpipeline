Mapping

  • BWA-aln is fine for a lot of datasets.
  • As long as reads are clipped well, bowtie2 will work.
  • BWA-mem might be better long term since it should eliminate the need for iterative mapping.

Note: BWA-mem won't map 30-mers or shorter

Iterative mapping: some argument about whether to start with long lengths and get shorter, or start short and get longer.

Pipelines

  • HICUP - lots of diagnostics, Ferhat says he likes it. Vijay isn't a fan. No visualization.
  • hicpro - what works well: fragment level or bin level assignment is very fast, good ICE implementation, also does allele specific stuff. No visualization. Matrix output is long/sparse format. Annoying things: directory structure is very important, stupid stuff like that.
  • Juicebox/juicer - is a pain pipeline wise
  • Hi-C-inspector - visualization?

Visualization

  • HiCPlotter - nice rotated TAD figures with optional annotation tracks. Pretty straightforward to use, written in python. Requires evenly spaced bins (Kate has a hacked version for restriction fragment-binned data)
